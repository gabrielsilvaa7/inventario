# Notas de atualização

O sistema oferece registro de contagens, consulta de materiais, supervisão por centro e depósito, exportação de listas de recontagem e relatórios.

A interface é publicada pelo GitHub Pages. Alterações no backend exigem publicar uma nova versão do projeto Google Apps Script existente.

Para validação, utilize o modo TESTE antes de iniciar o inventário oficial.
